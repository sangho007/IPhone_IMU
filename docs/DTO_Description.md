# DTO_Description.md 개요

`DTO_Description.md`는 센서 융합 결과로 생성되는 Telemetry DTO의 샘플 페이로드를 JSONC 형식으로 제공한다. 각 필드 옆에 한국어 주석을 배치해 데이터를 소비하거나 파싱하는 쪽에서 필드 의미를 빠르게 이해할 수 있도록 돕는다.

## 포함 정보
- `schema_version`: 메시지 규격 버전으로, 인코더와 디코더가 동일 스키마를 공유하는지 검증한다.
- `header`: 샘플 타임스탬프, 샘플 간 간격, 시퀀스, 세션 식별자 및 좌표계 명칭을 묶는다.
- `status`: 추적 엔진의 상태 문자열, 신뢰도(0~1), 추적 피처 수, 상태 사유, 플래그 배열을 포함한다.
- `pose_world_phone`: 월드 좌표계에서의 위치/사원수와 공분산, 유효 여부를 나타낸다.
- `velocity`, `acceleration`, `gyro`: kinematic 데이터 섹션으로, 각 축 값과 공분산, 데이터 출처, 유효 플래그를 담는다.
- `calib`: 휴대폰 ↔ 차량 좌표 변환 행렬과 월드 정렬 옵션을 기술한다.
- `origin_reset`, `integrity`: 기준점 초기화 정보와 CRC32 무결성 검증 값을 제공한다.

## 활용 팁
- 새로운 필드를 추가할 때는 예시 데이터와 주석을 업데이트해 백엔드/리더 애플리케이션에 변경 사항을 빠르게 공유한다.
- 수신 측 테스트를 작성할 때 이 샘플을 fixture로 사용하면 스키마 유효성 검사를 쉽게 자동화할 수 있다.
